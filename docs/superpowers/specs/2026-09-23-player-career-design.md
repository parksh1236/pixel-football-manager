# 선수 커리어 모드 설계

## 목표

신규 선수 한 명을 생성하고 주간 훈련, 경기 시뮬레이션, 계약과 이적을 거쳐 시즌과 통산 기록을 쌓는 독립 커리어를 제공한다.

## 선수 생성

선수 생성은 네 단계로 진행한다.

1. 기본 정보: 이름, 국가, 시작 나이, 키, 주발, 간단한 외형
2. 포지션: 주 포지션 1개와 보조 포지션 최대 2개
3. 선수 유형: 플레이메이커, 득점원, 윙어, 박스투박스, 수비 전문가, 골키퍼
4. 능력 조정: 유형별 기본 능력에서 총 10포인트를 빼거나 더해 재배분

능력치는 1~20 범위를 벗어나지 않는다. 재배분 후 총합은 유형의 초기 총합과 같아야 한다. 주 포지션은 능력을 모두 적용하고 보조 포지션은 숙련도에 따라 감점한다. 포지션 훈련으로 보조 포지션 숙련도를 주 포지션 수준까지 높일 수 있다.

생성 마지막 단계에서 시작 경로를 선택한다.

- 구단 선택: 8개 구단 중 하나와 즉시 계약
- 입단 테스트: 능력과 포지션에 따라 최대 3개 구단의 제안 수신
- 자유계약: 관심 구단의 출전 지위, 연봉과 기간을 비교해 선택

## 선수 정보와 성장

선수 정보에는 국가, 나이, 키, 주발, 주·보조 포지션, 숙련도, 세부 능력, 컨디션, 잠재력, 시장가치, 연봉, 계약 기간, 감독 신뢰도, 시즌 기록과 통산 기록을 표시한다.

성장량은 훈련, 출전 시간, 경기 평점, 나이와 잠재력으로 결정한다. 같은 능력을 연속 훈련하면 효율이 단계적으로 낮아진다. 체력이 낮을 때 높은 강도의 훈련을 하면 경기 컨디션과 부상 위험에 불이익을 준다. 부상은 훈련과 경기 출전을 일정 기간 제한하되 선수 데이터를 잃게 하지 않는다.

## 주간 훈련

월요일부터 일요일까지 각 날짜에 기술, 신체, 정신, 포지션, 회복 또는 휴식 중 하나를 배치한다. 경기 전날은 강한 훈련에 피로 불이익을 주고 경기 다음 날은 회복 효율을 높인다.

자동 훈련에서는 성장 목표와 강도를 선택한다. 코치는 경기일을 기준으로 훈련과 회복을 자동 배치하며 사용자가 언제든 수정할 수 있다. 일정 변경은 다음 진행 전에 저장한다.

## 출전과 경기 시뮬레이션

경기 전 감독 신뢰도, 능력, 컨디션, 포지션 숙련도로 선발, 벤치 또는 명단 제외를 결정한다. 출전하면 포지션과 역할에 맞는 개인 사건을 만든다.

- 패스, 킬패스, 드리블, 크로스
- 슈팅, 득점, 도움
- 태클, 가로채기, 선방
- 경고, 교체와 전술 변화

사건 결과는 관련 세부 능력, 컨디션, 정신력, 침착성, 천재성과 포지션 숙련도를 사용한다. 경기 후 평점, 득점, 도움, 패스 성공률, 슈팅, 수비 기록, 출전 시간, 경험치와 감독 신뢰도를 갱신한다.

## 경기 속도와 해설

경기 속도는 일시정지, 0.5배, 1배, 2배, 주요 장면만을 지원한다. 속도는 화면 표시 간격만 바꾸며 경기 결과와 사건 순서를 변경하지 않는다. 주요 장면만 모드는 킥오프, 득점 기회, 골, 경고, 교체와 경기 종료를 표시한다.

해설은 전술과 포메이션, 최근 활약, 컨디션, 패스 과정, 공간, 개인기와 천재성, 압박, 수비 간격, 역습 전환, 득점·도움·선방·실수, 경기 흐름, 평점 변화와 감독 반응을 다룬다. 같은 사건에 여러 문장 틀을 사용한다. 중요한 사건은 직전 2~3개 사건을 참조해 흐름을 설명하되 실제 결과와 다른 내용을 만들지 않는다.

## 장면 이미지

기존 슈팅, 선방, 창의적인 패스, 세리머니 이미지 4장은 재사용한다. 선수 모드에는 드리블, 도움, 태클, 경고, 교체, 훈련 성공, 계약 체결 이미지를 추가한다. 모든 이미지는 가상의 선수와 구단을 사용하고 기존 작품, 실제 선수, 로고와 텍스트를 포함하지 않는다.

이미지는 해당 사건이 발생했을 때만 표시하며 해설 문장을 대체 텍스트와 캡션으로 사용한다. 먼저 이미지를 불러온 뒤 읽을 수 있는 시간 동안 유지한다. 모바일에서는 경기장 아래에 배치한다.

## 계약과 커리어 진행

시즌 중 주전 경쟁, 개인 목표, 재계약과 이적 제안이 발생한다. 선수는 연봉, 계약 기간, 예상 지위와 구단을 비교해 선택한다. 선수 커리어는 구단 전체의 이적과 전술을 직접 조작하지 않는다.

## 오류와 경계 조건

- 생성 단계의 필수 정보와 능력 포인트가 유효하지 않으면 다음 단계로 이동하지 않는다.
- 부상 중에는 훈련과 출전 선택을 제한하고 남은 기간을 표시한다.
- 명단 제외 경기에서도 팀 결과와 시즌 일정은 정상 진행한다.
- 속도 변경과 일시정지는 같은 사건을 중복 처리하지 않는다.
- 저장 실패는 현재 화면을 유지하고 재시도 가능한 상태 메시지를 제공한다.

## 완료 기준

- 선수 생성 네 단계와 세 가지 시작 경로가 동작한다.
- 주간 일정을 직접 작성하거나 자동 훈련을 사용할 수 있다.
- 선발, 벤치, 명단 제외가 경기와 기록에 올바르게 반영된다.
- 다섯 경기 속도에서 동일한 사건과 결과를 유지한다.
- 풍부한 해설이 실제 사건과 이전 흐름을 일관되게 설명한다.
- 주요 장면 이미지가 사건에 맞게 표시된다.
- 성장, 피로, 기록, 감독 신뢰도, 계약과 저장이 새로고침 후 유지된다.
- 생성 검증, 훈련, 성장, 경기 기록, 속도 독립성과 저장 자동 테스트가 통과한다.
