# 매치데이 확장 설계

## 목표

기존 자동 경기 결과를 선수 22명의 움직임, 상황별 한국어 해설, 포메이션 편집, 일본 스포츠 애니풍 하이라이트로 시각화한다.

## 경기 전 포메이션

사용자는 4-3-3, 4-2-3-1, 3-5-2, 4-4-2, 5-3-2 중 하나를 선택한다. 선택 즉시 선발 11명이 해당 포메이션의 기본 좌표에 배치된다. 이후 경기장 위 선수를 포인터나 키보드로 이동해 자유 배치할 수 있다.

골키퍼는 자기 진영 페널티 구역 안에 있어야 한다. 필드 선수는 경기장 안에서 자유롭게 이동할 수 있지만 본래 포지션 영역을 크게 벗어나면 적합도 경고와 전력 감점이 표시된다. 자유 배치 좌표는 선택한 포메이션과 함께 저장한다.

## 경기장 움직임

경기장은 양 팀 11명과 공을 표시한다. 경기 엔진이 먼저 결과와 시간순 사건을 계산한 뒤, 화면은 각 사건 사이를 다음 상태로 보간한다.

- 대기: 포메이션 기본 대형 유지
- 빌드업: 공 소유 팀이 전진하고 상대는 수비 간격 축소
- 측면 공격: 윙어와 풀백이 측면으로 이동
- 역습: 공격수와 공이 빠르게 상대 진영으로 이동
- 슈팅: 슈터, 수비수, 골키퍼가 공 주변으로 이동
- 득점·선방: 해당 사건 위치에서 짧게 정지한 뒤 대형 복귀

실제 물리 엔진은 사용하지 않는다. 화면 애니메이션은 이미 결정된 경기 결과를 표현하며 결과를 다시 계산하지 않는다. `prefers-reduced-motion` 사용자는 사건 간 이동 없이 핵심 상태만 빠르게 확인한다.

## 경기 해설

사건은 `minute`, `type`, `teamId`, `playerId`, `targetPlayerId`, `outcome`, `zone`을 가진다. 화면은 사건 종류와 선수 이름을 조합해 한국어 문장을 만든다.

해설 대상은 전·후반 시작과 종료, 빌드업, 압박, 패스 차단, 드리블, 크로스, 슈팅, 선방, 골, 경고, 교체, 전술 효과다. 반복을 줄이기 위해 사건별 문장 틀을 여러 개 두되 경기 결과와 맞지 않는 문장을 만들지 않는다. 골과 경기 종료는 `aria-live` 영역에 즉시 전달한다.

## 하이라이트 이미지

외부 API 호출 없이 프로젝트에 포함된 이미지 4장을 재사용한다.

- 공격수의 결정적인 슈팅
- 골키퍼의 선방
- 미드필더의 창의적인 패스
- 득점 직후 팀 세리머니

이미지는 독창적인 가상 선수와 구단만 사용하며 일본 스포츠 애니메이션의 역동적인 연출, 강한 속도선, 셀 셰이딩을 적용한다. 기존 작품이나 실제 선수의 캐릭터·유니폼·로고는 모방하지 않는다. 골, 결정적 선방, 킬패스 사건에서만 표시하며 대체 텍스트에 사건 내용을 제공한다.

## 저장 호환성

저장 버전을 2로 올리고 `formation`, `customPositions`를 추가한다. 버전 1 저장 데이터는 나머지 시즌 기록을 유지한 채 기본 4-3-3 좌표를 채워 버전 2로 변환한다. 좌표가 없거나 경기장 범위를 벗어나면 해당 포메이션 기본 좌표로 복구한다.

## 완료 기준

- 다섯 포메이션을 선택하고 11명을 자유 배치할 수 있다.
- 경기 중 양 팀 22명과 공이 사건에 맞춰 이동한다.
- 해설과 점수, 하이라이트 이미지가 같은 사건을 설명한다.
- 키보드와 포인터 모두 포메이션 편집에 사용할 수 있다.
- 모바일 화면과 동작 감소 설정에서도 경기를 완료할 수 있다.
- 포메이션 좌표, 저장 변환, 사건 순서 자동 테스트가 통과한다.
