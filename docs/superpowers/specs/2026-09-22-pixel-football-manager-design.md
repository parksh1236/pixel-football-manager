# 픽셀 풋볼 매니저 설계

## 목표

설치 없이 브라우저에서 바로 플레이할 수 있는 한 시즌 분량의 축구 매니저 게임을 만든다. 플레이어는 한 구단을 맡아 선발과 전술을 정하고, 경기를 지켜보며, 최종 순위를 끌어올린다.

## 제품 범위

- 가상의 8개 구단이 홈·원정으로 한 번씩 맞붙는 14라운드 리그
- 사용자 구단의 18인 선수단과 선발 11명 관리
- 공격형, 균형형, 수비형 전술
- 라운드별 경기 시뮬레이션과 픽셀 경기장 중계
- 일정, 결과, 득점 기록, 승점·득실차 순위표
- 브라우저 로컬 저장과 새 시즌 시작

이적, 계약, 재정, 훈련, 부상, 유소년, 온라인 기능은 첫 버전에 포함하지 않는다.

## 사용자 흐름

첫 실행 시 사용자는 자신의 구단을 확인하고 대시보드에서 다음 상대와 현재 순위를 본다. 선수단 화면에서 선발을 바꾸고 전술을 선택한 뒤 경기를 시작한다. 경기는 시간과 주요 장면이 순차적으로 진행되고, 종료 후 해당 라운드의 다른 경기까지 계산된다. 결과가 순위표와 일정에 반영되며 다음 라운드로 넘어간다. 14라운드가 끝나면 최종 순위와 시즌 성적을 보여주고 새 시즌을 시작할 수 있다.

## 화면 구성

상단에는 구단명, 라운드, 전적과 저장 상태를 둔다. 왼쪽 탐색 메뉴에서 대시보드, 선수단, 일정, 순위표로 이동한다. 중앙 콘텐츠 영역은 선택한 화면을 표시하며, 경기 중에는 픽셀 경기장, 스코어보드, 경기 시간, 주요 장면 로그를 함께 보여준다.

시각 스타일은 어두운 남색 바탕, 잔디색과 호박색 강조색, 단단한 픽셀 테두리를 사용한다. 아이콘과 경기장은 CSS 및 Canvas로 그려 외부 이미지나 폰트에 의존하지 않는다. 작은 화면에서도 한 열로 재배치되어 모든 조작을 사용할 수 있어야 한다.

## 게임 상태

단일 상태 객체가 구단, 선수, 일정, 현재 라운드, 전술, 경기 결과를 보관한다. 화면 전환이나 선발 변경은 이 상태를 갱신한 뒤 필요한 영역을 다시 그린다. 저장 가능한 상태는 `localStorage`에 기록하고, 손상되거나 형식이 맞지 않는 저장 데이터는 사용하지 않고 새 시즌 상태로 복구한다.

선수는 이름, 포지션, 능력치, 컨디션, 선발 여부를 가진다. 선발은 정확히 11명이어야 하며 골키퍼가 최소 1명 포함되어야 한다. 사용자가 후보를 선택하면 같은 포지션의 선발 선수와 교체하는 방식으로 잘못된 인원 구성을 방지한다.

## 경기 시뮬레이션

팀 전력은 선발 선수 능력치 평균, 컨디션, 홈 이점, 선택한 전술로 계산한다. 공격형은 득점 기회와 실점 위험을 함께 높이고, 수비형은 둘을 함께 낮추며, 균형형은 보정하지 않는다. 경기별 난수는 득점 시점과 주요 장면에 다양성을 주되 팀 전력 차이가 승리 확률에 반영되어야 한다.

경기는 브라우저에서 짧은 간격으로 90분까지 진행된다. 주요 장면이 발생하면 로그와 경기장 표시를 갱신한다. 경기 종료 시 사용자 경기와 같은 라운드의 나머지 경기를 한 번만 확정하고, 승점과 득실차를 다시 계산한다.

## 오류와 경계 조건

- 경기가 진행 중일 때 중복 시작을 막는다.
- 완료된 라운드는 다시 계산하지 않는다.
- 시즌 종료 후에는 경기 시작 대신 최종 결과와 새 시즌 동작을 제공한다.
- 저장 실패는 게임 진행을 막지 않으며 화면에 간단한 상태 메시지를 보여준다.
- 모든 버튼은 키보드로 사용할 수 있고 현재 선택과 포커스가 시각적으로 구분되어야 한다.

## 구현 구조

의존성과 빌드 과정이 없는 정적 웹 앱으로 구성한다.

- `index.html`: 화면의 의미 구조와 기본 콘텐츠
- `styles.css`: 반응형 레이아웃과 픽셀아트 표현
- `game.js`: 데이터 생성, 상태 변경, 경기 시뮬레이션, 저장, 렌더링
- `game.test.js`: 순위 계산과 경기 상태의 최소 회귀 검증

별도 프레임워크, 서버, 이미지 생성물은 사용하지 않는다. 코드로 그리는 그래픽만으로 필요한 품질을 낼 수 있어 프로젝트 외부 자산 관리가 생기지 않는다.

## 완료 기준

- 로컬 정적 서버에서 오류 없이 실행된다.
- 선발 교체와 세 전술 선택이 다음 경기 계산에 반영된다.
- 한 시즌을 14라운드까지 진행할 수 있다.
- 모든 경기 결과가 일정과 순위표에 일관되게 반영된다.
- 새로고침 후 현재 시즌을 이어서 플레이할 수 있다.
- 데스크톱과 모바일 너비에서 주요 화면과 조작이 겹치지 않는다.
- 순위 계산 및 라운드 중복 처리 검증이 통과한다.
