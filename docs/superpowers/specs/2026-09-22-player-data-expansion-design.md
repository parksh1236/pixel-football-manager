# 선수 데이터 확장 설계

## 목표

선수의 능력과 개성이 경기 장면, 포메이션 적합도, 시장가치와 연봉에 일관되게 반영되도록 세부 데이터를 확장한다.

## 선수 정보

선수는 기존 이름, 포지션, 컨디션에 다음 정보를 가진다.

- 신상: 국가, 나이, 주발, 키, 잠재력
- 공격: 골 결정력, 슈팅, 드리블, 크로스, 개인기
- 패스: 짧은 패스, 긴 패스, 시야
- 수비: 태클, 수비 위치선정, 몸싸움
- 신체: 속도, 가속력, 체력
- 정신: 정신력, 침착성, 판단력, 천재성
- 골키퍼: 선방, 반사신경, 공중볼

세부 능력치는 1부터 20까지의 정수다. 필드 선수의 골키퍼 능력과 골키퍼의 필드 능력도 데이터에는 존재하지만 종합 능력 계산에서 낮은 가중치를 사용한다.

## 종합 능력과 역할 적합도

종합 능력은 포지션별 핵심 능력의 가중 평균을 100점 척도로 변환한다. 역할 적합도는 선수 포지션과 포메이션 좌표의 영역, 주발, 관련 세부 능력을 함께 평가한다. 적합하지 않은 위치에 배치할 수는 있지만 팀 전력에 감점이 적용된다.

경기 사건은 관련 능력을 직접 비교한다. 크로스는 크로스·시야와 수비 위치선정·공중볼, 드리블은 드리블·개인기·가속력과 태클·속도, 킬패스는 시야·판단력·천재성과 상대 수비 위치선정을 사용한다. 정신력은 열세와 경기 막판의 능력 하락을 줄이고, 침착성은 결정적인 슈팅과 선방에 반영한다. 천재성은 창의적 선택의 빈도와 성공 가능성을 높이지만 실패하면 역습 사건으로 이어질 수 있다.

## 가치와 연봉

시장가치는 종합 능력, 잠재력, 나이, 포지션 희소성, 계약 잔여 기간으로 계산한다. 표시 단위는 억 원이며 내부 값은 만 원 단위 정수로 저장한다. 주급은 종합 능력, 나이, 시장가치로 계산하고 만 원 단위로 표시한다. 동일한 데이터는 항상 동일한 값이 나오도록 가치 계산에는 난수를 사용하지 않는다.

## 화면

선수단 카드에는 국가, 나이, 포지션, 종합 능력, 시장가치, 주급을 표시한다. 카드를 선택하면 분류별 세부 능력, 주발, 키, 잠재력, 현재 포메이션 역할 적합도를 보여준다. 좁은 화면에서는 세부 패널이 카드 아래에 열린다.

## 저장 호환성

저장 버전을 3으로 올린다. 이전 선수는 이름과 포지션을 시드로 사용해 고정된 국가·나이·세부 능력·계약 값을 생성한다. 기존 종합 능력과 크게 어긋나지 않도록 세부 능력의 평균을 보정한다. 잘못된 능력치는 1~20, 나이는 16~40, 키는 155~205cm 범위로 제한한다.

## 완료 기준

- 18명 모두 승인된 신상 정보와 세부 능력을 가진다.
- 종합 능력과 역할 적합도가 포지션별 가중치로 계산된다.
- 개인기, 정신력, 천재성이 관련 경기 사건에 반영된다.
- 시장가치와 주급이 새로고침 후에도 변하지 않는다.
- 저장 변환, 능력 범위, 가치 계산 자동 테스트가 통과한다.
