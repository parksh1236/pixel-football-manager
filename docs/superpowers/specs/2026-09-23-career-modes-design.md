# 커리어 모드 기반 설계

## 목표

게임 시작 시 감독 모드와 선수 모드 중 하나를 선택해 독립된 커리어를 만들고, 최대 3개 저장 슬롯에서 이어서 플레이할 수 있게 한다. 두 모드는 같은 리그, 일정, 선수와 경기 엔진을 공유한다.

## 시작 화면

게임을 열면 새 커리어, 이어하기, 저장 관리 메뉴를 보여준다. 저장이 없으면 새 커리어를 기본 동작으로 강조한다.

새 커리어에서 모드를 고른다.

- 감독 모드: 감독 이름, 국가, 담당 구단을 정한다.
- 선수 모드: 선수 생성 절차로 이동한다.

감독 모드는 현재 구현된 선수단, 포메이션, 전술, 경기, 일정과 순위 기능을 그대로 사용한다. 이후 승인된 선수 데이터와 이적시장 확장은 감독 모드에 연결한다.

## 저장 슬롯

저장 슬롯은 최대 3개다. 각 슬롯에는 모드, 커리어 이름, 소속 구단, 시즌, 라운드, 마지막 저장 시각을 표시한다. 슬롯 선택은 이어하기로 연결되고, 빈 슬롯은 새 커리어 생성으로 연결된다.

공통 저장 구조는 다음 값을 가진다.

- `version`: 저장 형식 버전
- `mode`: `manager` 또는 `player`
- `career`: 모드별 주인공과 진행 정보
- `world`: 구단, 선수, 일정, 결과, 순위와 재정
- `savedAt`: ISO 형식 저장 시각

감독 모드는 선수단, 전술, 포메이션, 이적과 구단 재정을 `career`에 저장한다. 선수 모드는 내 선수, 훈련 일정, 감독 신뢰도, 계약, 개인 기록을 저장한다. 리그의 공통 상태는 `world`에 저장한다.

## 저장과 복구

라운드 종료, 계약 체결과 새 커리어 생성 직후 자동 저장한다. 사용자가 중요한 설정을 바꾸면 현재 슬롯에 저장한다. 한 슬롯의 파싱이나 형식 검증이 실패해도 다른 슬롯은 정상적으로 불러온다. 손상된 슬롯은 복구 불가 상태로 표시하고 새 커리어로 덮어쓸 수 있다.

기존 단일 저장 `pixel-manager-season-v1`은 감독 모드의 첫 번째 빈 슬롯으로 한 번만 변환한다. 시즌, 라운드, 경기 결과, 선수, 전술과 포메이션을 유지한다. 변환 성공 전에는 기존 키를 삭제하지 않는다.

## 화면 구조

시작 화면과 커리어 화면을 하나의 정적 웹 앱에서 전환한다. 커리어를 종료하면 시작 화면으로 돌아가며 저장 슬롯은 유지된다. 헤더에는 현재 모드와 저장 슬롯을 표시해 어떤 커리어를 플레이 중인지 구분한다.

## 완료 기준

- 감독 모드와 선수 모드의 새 커리어를 만들 수 있다.
- 최대 3개 슬롯을 독립적으로 저장하고 이어서 플레이할 수 있다.
- 손상된 슬롯 하나가 다른 슬롯 로딩을 막지 않는다.
- 기존 단일 저장이 감독 모드 슬롯으로 변환되고 진행 기록이 유지된다.
- 새로고침 후 현재 모드와 슬롯이 복원된다.
- 저장 변환, 슬롯 격리와 최대 개수 자동 테스트가 통과한다.
